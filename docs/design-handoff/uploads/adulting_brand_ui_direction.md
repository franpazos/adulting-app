# Adulting.app — Brand & UI Direction

Use this document together with the selected visual references:

- `Direction 1 — Soft Premium` (light mode)
- `Direction 1 — Soft Premium` (dark mode)

These images are the primary visual references. This document translates that visual direction into practical implementation guidance.

---

## 1. Final chosen direction

The selected brand direction for **Adulting.app** is:

- **Logo direction:** `Option 1B`
- **Overall brand direction:** `Direction 1 — Soft Premium`
- **Core feeling:** **calm, premium, effortless**

The product should feel:

- modern
- subtly playful
- premium, but not luxurious in a cold way
- warm enough for a household/shared-life app
- polished and iPhone-like
- professional and trustworthy
- easy to use, not intimidating

This is **not** a loud fintech brand.
This is **not** a banking app aesthetic.
This is **not** a generic dashboard template.

The goal is a soft, premium personal finance product that feels friendly and highly usable.

---

## 2. Brand personality

The brand should communicate:

- **clarity**
- **control without stress**
- **financial confidence**
- **shared life / household practicality**
- **modern taste**

Tone keywords:

- calm
- premium
- clean
- soft
- tech-forward
- approachable
- trustworthy
- subtle

The brand should feel a little playful because the name is **Adulting.app**, but the visual execution must stay mature and restrained.

---

## 3. Logo direction

### Chosen logo
Use the logo direction shown in **Option 1B**.

### Logo concept
The symbol should feel like a combination of:

- the letter **A**
- a subtle **house / roof** gesture
- a slight feeling of **balance / finance / structure**

It should remain **abstract**, not literal.
The symbol should not look like a cartoon house.
The symbol should not feel childish.

### Wordmark
Use the **Option 1B** wordmark feel as the main reference.

The wordmark should feel:

- sleek
- humanist-tech
- modern
- slightly distinctive
- premium
- readable
- subtle

`Adulting` should visually carry more weight than `.app`.
The `.app` suffix can be treated as lighter, more secondary, and often purple.

### Logo usage principles
- Prefer generous spacing around the logo.
- Keep the logo fairly small/subtle in-app.
- Branding should support the product, not dominate it.
- In headers, the logo mark alone can often be enough.
- Use the full wordmark mostly in splash/onboarding/about/marketing-style surfaces.

---

## 4. App icon direction

Use the selected icon direction from the final concept:

- circular / coin-like icon
- purple primary fill
- white logo mark centered
- slight depth / soft dimensionality
- premium, iOS-friendly appearance

### App icon feel
The icon should not be flat and dead.
It should have **slight depth**, but avoid excessive gloss or skeuomorphic effects.

Think:

- soft lighting
- subtle bevel / elevation
- crisp white mark
- clean silhouette

Do not overdo gradients or shadows.
It should still feel modern and timeless.

---

## 5. Color system

### General principle
The color system should be anchored around **violet** as the hero brand color.
Supporting colors should feel clean and intentional, not noisy.

### Core palette
Use this palette as the primary implementation reference:

- **Violet / Brand Primary:** `#7B5CF6`
- **Green / Positive:** `#22C55E`
- **Coral / Expense / Alert-soft:** `#FF7D6B`
- **Blue / Info / Debt / Neutral financial state:** `#3B82F6`
- **Amber / Pending / Warning / Secondary highlight:** `#F59E0B`

These exact values can be adjusted slightly in implementation if needed for accessibility, but the overall relationship should remain the same.

### Functional color meaning
- **Violet** = brand, primary CTA, active state, navigation highlight
- **Green** = positive, income, progress, on-track, successful state
- **Coral** = expense, negative, caution, but softened and friendly
- **Blue** = informational, debt-related, secondary financial state
- **Amber** = pending, reminder, sync, warning-lite

### Color usage guidance
- Violet should be the most recognizable brand color.
- Use color with restraint.
- Most surfaces should remain neutral.
- The app should not look rainbow-heavy.
- The supporting colors should mostly appear in charts, states, indicators, and small accents.

---

## 6. Neutrals and surfaces

### Light mode
Light mode should use:

- warm off-white backgrounds
- soft neutral cards
- subtle borders/dividers
- dark text with strong readability
- restrained shadow depth

Suggested light neutrals:

- page background: warm white / soft cream
- cards: clean white or very slightly warm white
- borders: light neutral gray with low contrast
- text primary: deep navy-charcoal, not pure black
- text secondary: muted gray

### Dark mode
Dark mode should use:

- near-black or deep charcoal backgrounds
- subtle violet-tinted dark surfaces
- crisp light text
- elegant contrast
- no muddy gray overlays

Suggested dark neutrals:

- page background: deep charcoal / near-black
- cards: slightly elevated dark surfaces
- borders: soft dark borders with enough separation
- text primary: near-white
- text secondary: cool light gray

Dark mode should feel like a premium companion to light mode, not a separate design system.

---

## 7. Typography

### Chosen direction
Use this typography pairing direction as the primary reference:

- **Brand / Display font:** `Sora SemiBold` or something very close in feel
- **UI / Body font:** `Inter Regular` or something very close in feel

### Display font requirements
The brand/display font should feel:

- modern
- geometric-humanist
- clean
- slightly expressive
- tech-forward but not harsh
- premium and readable

### Body/UI font requirements
The body font should feel:

- neutral
- highly legible
- modern
- clean
- unobtrusive

### Typography hierarchy
Use a strong but simple hierarchy:

- large headline for primary screens/cards
- medium section headers
- clear labels
- soft small secondary text

Do not use too many weights.
Keep typography disciplined.

### What to avoid
- do not use childish rounded novelty fonts
- do not use fonts that feel too corporate/banking
- do not use overly editorial serif-heavy systems
- do not make typography too thin or too light for mobile

---

## 8. UI style principles

The app should feel like a **high-quality iPhone-first PWA**.

### Core UI qualities
- rounded cards
- strong spacing
- soft shadows
- subtle borders
- clean iconography
- smooth hierarchy
- touch-friendly controls
- balanced use of color
- minimal clutter

### Visual style keywords
- soft premium
- iOS-inspired
- elegant
- modern
- quiet confidence
- clean but not sterile

### Card style
Cards should:

- have comfortable padding
- use rounded corners generously
- feel lightly elevated
- avoid hard outlines unless necessary
- prioritize readable grouping of information

### Shadows
Shadows should be:

- soft
- low drama
- enough to separate surfaces
- stronger in light mode than dark mode, but still subtle overall

### Borders
Borders/dividers should be:

- thin
- low contrast
- used for structure, not decoration

### Iconography
Icons should feel:

- modern
- simple
- slightly rounded if possible
- consistent in stroke/weight

---

## 9. Navigation and controls

### Bottom navigation
The bottom navigation is one of the signature UI elements.

It should:

- feel premium and central to the app
- have a clear active state using violet
- support a prominent central add button
- remain visually balanced, not bulky

### Central add button
The center add button should:

- be more prominent than the other nav items
- use violet as the primary color
- feel elevated and tappable
- look like a key action, not a gimmick

This button is one of the strongest parts of the concept and should be preserved.

### Controls
Use controls that feel native-adjacent:

- segmented controls
- pill filters
- smooth toggles
- bottom sheets / modals where appropriate
- clear primary and secondary button hierarchy

---

## 10. Charts and financial visuals

Charts should feel integrated into the brand, not pasted in.

### Guidelines
- keep charts simple and readable
- use the functional palette consistently
- avoid busy chart styles
- avoid excessive gradients in charts
- do not make analytics look like a trading platform

### Preferred chart tone
- clean donut charts
- simple line graphs
- compact progress bars
- small categorical indicators

They should support clarity, not overwhelm the user.

---

## 11. Light mode guidance

Light mode should feel:

- airy
- premium
- calm
- easy to scan

### Priorities in light mode
- soft background contrast
- violet as the main brand accent
- clean white cards
- subtle depth
- lots of whitespace

Light mode should be the clearest expression of the brand.

---

## 12. Dark mode guidance

Dark mode should feel:

- premium
- elegant
- crisp
- confident
- modern

### Priorities in dark mode
- preserve the same layout logic as light mode
- avoid over-saturating purple everywhere
- keep the brand purple vivid but controlled
- ensure charts and colored indicators remain readable
- use glows very carefully, if at all

Dark mode should not become cyberpunk.
It should remain refined.

---

## 13. Branding intensity

Branding should stay **subtle**.

This app should not feel like a heavy-branded marketing site.
The product UI should be the main character.

### Good approach
- small logo mark in app header
- restrained use of branded surfaces
- violet used for important emphasis only
- plenty of neutral breathing room

### Bad approach
- putting the logo everywhere
- purple gradients on every surface
- overdecorating empty states
- turning every chart and panel into branding

---

If illustrations or decorative graphics are needed, they should be:

- very minimal
- soft
- friendly
- neutral
- modern

Possible mood references:

- subtle plant/lifestyle warmth
- clean objects
- calm home-life cues
- simple geometric accents

Do not use loud cartoon illustrations.
Do not use cheesy fintech people illustrations.

---

## 15. Motion / interaction feel

Motion should feel:

- smooth
- short
- polished
- responsive
- understated

Use animation to support quality, not spectacle.

Good examples:
- gentle card transitions
- soft button press states
- smooth sheet/modal entrances
- subtle chart drawing
- clean theme switching

Avoid flashy motion or overshooting spring effects.

---

## 16. Do / Don't

### Do
- keep the product calm and polished
- use violet as the clear brand anchor
- preserve the selected logo and icon direction
- use rounded, premium surfaces
- make dark mode feel intentional and elegant
- keep typography readable and modern
- let whitespace do a lot of the work
- make the add button feel special

### Don’t
- do not make it look like a bank portal
- do not make it feel childish or cutesy
- do not overuse gradients
- do not make coral too aggressive
- do not overload the interface with too many colored elements
- do not make dark mode overly neon or gamer-like
- do not use inconsistent icon styles
- do not crowd screens with too much data

---

## 17. Implementation summary for the builder

When implementing the app, treat these as the final visual priorities:

1. Preserve the **Option 1B logo feel**.
2. Preserve the **Direction 1 — Soft Premium** mood.
3. Use **violet** as the central brand color.
4. Build both **light mode and dark mode** as first-class themes.
5. Use **Sora-like display typography** and **Inter-like body typography**.
6. Keep the UI **iPhone-like, rounded, premium, soft, and highly usable**.
7. Ensure the product feels **professional and trustworthy**, but also personal and modern.

If something is unclear, bias toward:

- simplicity
- elegance
- readability
- softness
- premium restraint

Not toward visual noise or fintech cliché.
